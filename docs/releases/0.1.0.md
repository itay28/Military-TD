## Notes

<!-- For the reviewer: highlights, known issues, anything the changelog doesn't say. Kept when this report is regenerated. -->

**Highlights.** The whole MVP loop works in the browser: one 16 × 10 map, the Rifle Nest, Infantry, one wave of 8, Money and Lives, the HUD with Start Wave, click-to-place, tracers, and the Victory/Defeat end screen with Restart. All of it is drawn with shapes; the version shows in the bottom-right corner. Behind it: a pure-TS Simulation with headless scenarios, the Playwright harness with test-mode flags (`?test=1`, `?step=manual`, `?anim=0`, `?speed=N`), CI, release-please and the itch.io deploy.

**Known limits.**
- One wave, so a game lasts well under a minute. This build proves the loop; making it fun is v0.2.0.
- Desktop browser with a mouse only. Touch input is planned for v0.7.0.
- The HUD bar sits above the canvas, so the itch.io embed needs about 768 × 530, not the 768 × 480 the README gives.

**Moved out.** #134 (canvas e2e checks for the range ring, tracers and draw order) moved to v0.2.0: test-only follow-ups from #12 and #15, no change for the player.

**Release note.** This is the first release, so release-please proposed 1.0.0 (its default when there is no earlier tag). The `Release-As: 0.1.0` footer on this PR is what sets the version; don't merge the release PR until it says 0.1.0.
