# Size task prompt

The prompt of the sizing agent: `.github/workflows/size-issue.yml` runs Claude (Sonnet) with it when an issue is labelled `ready-for-agent` and has no Size on the project board and no `size:*` label (#205). The workflow names the issue.

## The task

You size one issue so auto-start can pick it up. Nobody is watching; don't ask questions.

1. **Read the issue:** `gh issue view <n> --json title,body,labels,milestone,comments`. Read only what you need to judge it; open a file the issue names if that helps you judge the work.
2. **Judge it** with the **Priority** and **Size** tables in `docs/agents/issue-tracker.md` → **Project board**. Size is the work for one agent session, counting tests and docs. Priority is judged against the issue's milestone. When unsure between two levels, pick the bigger Size and the less urgent Priority.
3. **Label it:** one size and one priority label, in one command: `gh issue edit <n> --add-label size:<XS|S|M|L|XL> --add-label priority:<P0|P1|P2|P3>`. Skip the priority label if the issue already has a `priority:*` label. Don't change any other label.
4. **Comment once,** one line on why: `gh issue comment <n> --body "Sized by the sizing agent: Size M (…), Priority P1 (…)."` End the body with a blank line and `_Generated by [Claude Code](https://claude.ai/code)_`.

*Board sync* copies the labels to the board and removes them; you don't touch the board.
