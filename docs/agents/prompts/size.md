# Size task prompt

The prompt of the sizing agent: `.github/workflows/size-issue.yml` runs Claude (Sonnet) with it when an issue is labelled `ready-for-agent` and lacks a Size (none on the project board and no `size:*` label) or, for game work, a milestone (#205, #225). *Board sync* also dispatches it for issues the label event missed. The workflow names the issue and says what it lacks: `Needs a Size: true|false` and `Needs a milestone: true|false`.

## The task

You size one issue so auto-start can pick it up. Nobody is watching; don't ask questions in a chat.

1. **Read the issue:** `gh issue view <n> --json title,body,labels,milestone,comments`. Read only what you need to judge it; open a file the issue names if that helps you judge the work.
2. **Size and Priority** (only when `Needs a Size: true`): judge them with the **Priority** and **Size** tables in `docs/agents/issue-tracker.md` → **Project board**. Size is the work for one agent session, counting tests and docs. Priority is judged against the issue's milestone. When unsure between two levels, pick the bigger Size and the less urgent Priority. Label it with one size and one priority label in one command: `gh issue edit <n> --add-label size:<XS|S|M|L|XL> --add-label priority:<P0|P1|P2|P3>`. Skip the priority label if the issue already has a `priority:*` label. Don't change any other label.
3. **Milestone** (only when `Needs a milestone: true`): game work must carry the version it ships in, so it isn't built ahead of its time. Pick it from the roadmap in `docs/PLAN.md` and the milestone descriptions (`gh api repos/itay28/Military-TD/milestones`), and set it with its exact title: `gh issue edit <n> --milestone "<title>"`. Never change a milestone the issue already has, and never give an `area:infra` issue one (infra work needs none). If you can't tell which milestone it belongs to, don't guess: add `needs-info` (`gh issue edit <n> --add-label needs-info`) and put the question in your comment.
4. **Comment once,** one line on what you set and why: `gh issue comment <n> --body "Sized by the sizing agent: Size M (…), Priority P1 (…), milestone v0.3.0 (…)."` Leave out the parts you didn't set. End the body with a blank line and `_Generated by [Claude Code](https://claude.ai/code)_`.

*Board sync* copies the labels to the board and removes them; you don't touch the board.
