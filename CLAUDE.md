# Military-TD

A basic military-themed tower defense game.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on itay28/Military-TD (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Plan

Roadmap, game flow, architecture and milestones: `docs/PLAN.md`. Work items are GitHub issues under the "MVP roadmap" tracking issue.
